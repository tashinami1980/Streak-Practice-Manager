Создай приложение по моему референсу. Приложение с названием Streak Practice Manager - для продуктивности. Основная идея - мотивация за счет очевидности прогресса. итак, в основном окне (скрин 1) располагается основное меню. в левом верхнем углу располагается кнопка добавления задачи. при ее нажатии снизу под задачами появляются "..." для заполнения (новая строчка) и автоматически проставляются незаполненные флажки на 2 недели вперед. сразу под кнопкой располагаются сами задачи - при нажатии на нее, оно перейдет в меню задачи, описание которого будет позже. далее, на одном уровне с кнопкой добавления, располагаются временные отметки: 3 days, 7 days, 2 weeks. они располагаются прямо над соответствующим им количеством флажков (подбери оптимальное расстояние). при нажатии на флажок, он закрашивается как зеленый флажок на скрине. при нажатии на закрашенный флажок, он вновь становится незакрашенным. это функции основного окна. 

меню выбранной задачи открывается двойным нажатием по имени задачи в основном меню, изображено на скрине 2. сверху с выравниванием по центру располагается название задачи, справа кнопка перезапуска, при нажатии на которую открывается окно Task submission, речь о котором пойдет чуть позже. Левее и ниже под названием задачи располагается Current Streak, а под ним значение текущего выполнения (количество отмеченных флажков по этой задаче) в виде "xx days", где xx - количество отмеченных флажков. под этими двумя объектами располагается те же самые объекты с одинаковой логикой, только уже Best Streak - т.е. лучшая серия из отмеченных по этой задаче флажков. правее Current Streak располагается Heatmap - тепловая карта в виде минималистичного календаря, в котором показывается в разрезе времени количество выполнений. реализуется также как на скрине - 10 столбцов в ширину, 7 в длину. если нет ни одного заполненного флажка, выдели текущий день как первый квадратик на Heatmap, сделай ему черную обводку. если есть какие-то заполненные значения, то отметь текущий день так, чтобы в этот календарь попадало максимальное количество заполненных флажков. но обязательно чтобы все шло строго согласно настоящим датам. под xx days объекта Best Streak располагается кнопка "Back to Tasks", в виде прямоугольника с закругленными краями, закрашенный светло-серым цветом. выравнивание объектов смотри по скрину - Current Streak и Best Streak на одинаковом отдалении друг от друга, Heatmap также должен быть по высоте такой же как и Current Streak и Best Streak вместе взятые - все должно смотреться эстетично. 

так вот, при нажатии на кнопку сброса (перезапуска) задачи, перекрывая все, кроме названия задачи (или можно сделать чтобы перекрывало половину объектов, но накладывало размытие на задние объекты), открывается форма закрытия (которая представлена на скрине 2 справа). в этом окне есть текст "Are you sure you want to start over?" и под этим текстом две кнопки - No и Yes. при нажатии на Yes, текущий стрик сбрасывается и если результат этого стрика больше чем текущий рекорд, то текущий рекорд перезаписывается на рекорд этого стрика.
